# Security and responsible disclosure

This repository studies a dual-use white-box editing attack in order to evaluate checkpoint hardening. It may help reproduce refusal-removal behavior. Use it only on models and infrastructure you are authorized to test.

Do not publish generated harmful responses, access tokens, private prompts, proprietary model weights, or ready-to-redistribute jailbroken checkpoints. Prefer aggregate refusal/KL results, configuration manifests, and redacted logs.

The defense raises the cost of tested low-distortion editing paths; it does not provide universal white-box security and does not cover arbitrary retraining, weight replacement, or model substitution.

For a suspected vulnerability or accidental sensitive artifact, contact the maintainers privately before opening a public issue. If GitHub Security Advisories are enabled for this repository, please use that channel; otherwise contact the project maintainers through an appropriate private channel.
