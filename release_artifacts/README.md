# Release artifacts

This directory contains selected structured artifacts for the two recommended public recipes:

- `qwen3_8b/`
- `gemma3_12b/`

Each model directory contains:

- Step-1 and Phase-1/Phase-2 JSON summaries;
- bait-reference metadata;
- a 200-trial Heretic journal used for KL-constrained minimum-refusal summaries.

These artifacts are intended to make the headline validation table auditable without committing generated model checkpoints or local cache files.
