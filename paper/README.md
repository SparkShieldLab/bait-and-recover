# Paper

This directory contains the accepted AACL-IJCNLP 2026 Main paper accompanying this release.

Included PDF: `Bait-and-Recover.pdf`.

arXiv version: [arXiv:2609.05794](https://arxiv.org/abs/2609.05794).

Title: Bait-and-Recover: Poisoning Internal Refusal Signals to Defend LLMs against White-Box Editing Jailbreaks

Authors: Tian Gao, Zhipeng Xie, Yuhao Wu, Junhua Liu, and Xin Fang

The code and artifacts in this repository provide the cleaned release implementation, selected validation artifacts, and patch-based Heretic integration for the accepted paper.
